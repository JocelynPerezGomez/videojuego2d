# 🎃 Cementerio Embrujado - Videojuego 2D

## Contexto
Proyecto desarrollado para el examen de Segundo Seguimiento de la materia de **Graficación**
de la carrera de Ingeniería en Sistemas Computacionales. El objetivo es aplicar la API
**Canvas 2D** de HTML5 para construir un videojuego 2D con temática de Halloween.

## Objetivo
Desarrollar una aplicación web que muestre 25 objetos 2D animados con las imágenes temáticas
como: fantasmas, calabazas, tumbas, zombis y murciélagos que se desplacen por el canvas,
reaccionen a colisiones y puedan ser eliminados por el usuario mediante clics del mouse.

## Justificación
El uso de Canvas 2D permite practicar conceptos fundamentales de graficación por
computadora: transformaciones, animación por frames, detección de colisiones,
carga de sprites e interacción con el usuario. 


## Operación del juego
1. Abre el sitio en el navegador.
2. Haz clic en cualquier parte de la pantalla para activar la música.
3. Mueve el mouse sobre el canvas: verás un cursor personalizado.
4. Haz clic sobre un objeto (fantasma, calabaza, tumba, zombi o murciélago) para eliminarlo.
5. El objeto desaparecerá y reaparecerá en otra zona aleatoria.
6. El contador incrementará con cada clic acertado.
7. Los objetos rebotan en los bordes y entre sí, mostrando un destello al chocar.


## Conclusiones
El proyecto permitió aplicar los conceptos de graficación 2D vistos en clase, reforzando
el manejo de Canvas, la animación por frames, la detección de colisiones y el control
de versiones con Git. Se logró una aplicación interactiva, temática y funcional que
cumple con todas las reglas de negocio planteadas en el examen.
